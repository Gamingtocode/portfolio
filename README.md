# ✨ Personal Portfolio / Link-in-Bio

A clean, modern, and fully responsive personal portfolio page.  
Perfect for GitHub Pages — zero dependencies, pure HTML + CSS + vanilla JS.

## 🚀 Features

- Beautiful light & dark mode (with system preference detection)
- Fully responsive (mobile-first)
- Smooth hover animations
- Easy to customize
- Ready for GitHub Pages

## 🛠 How to use

1. Edit `index.html`:
   - Change your name, tagline, and bio
   - Update the avatar image
   - Update all the links (GitHub, Twitter, LinkedIn, Email, etc.)
   - Edit the project cards

2. Deploy to GitHub Pages (see below)

## 📦 Deploy to GitHub Pages

1. Push this code to a GitHub repository
2. Go to **Settings → Pages**
3. Under "Source", select **Deploy from a branch** → `main` → `/ (root)`
4. Click Save

Your site will be live at:  
`https://YOUR_USERNAME.github.io/YOUR_REPO/`
